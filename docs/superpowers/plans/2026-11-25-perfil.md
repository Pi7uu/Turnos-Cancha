- Acciones ( RF-02 ): fila `Mis reservas` ( clave `ValueKey('fila-mis-reservas')` ) → `widget.onIrAMisReservas?.call()`; en `MainShell` ese callback cambia al tab Mis reservas ( mismo patrón que `onVolver` de MisReservasScreen ). `Cerrar sesión` → `Navigator.of(context).pushAndRemoveUntil(MaterialPageRoute(builder: (_) => const LoginScreen()), (route) => false)` ( clave `ValueKey('cerrar-sesion')` ). Filas `Mis datos`/`Métodos de pago`/`Notificaciones`/`Ayuda`: `GestureDetector` sin acción ( inertes, semántica accesible ).
- `MainShell`: el tab Perfil deja de ser placeholder → `PerfilScreen(onIrAMisReservas: () => setState(() => _tab = TabApp.misReservas))`. Las claves `ValueKey('placeholder-perfil')` **se eliminan** ( ya no es placeholder ) — actualizar los tests de navegación que las referencien ( cambio de alcance documentado en el spec ).
- Tipografía: fuente por defecto si Inter no está configurada. Sin tokens nuevos. Sin HTTP.
