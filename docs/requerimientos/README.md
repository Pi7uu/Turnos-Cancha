# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. La reserva exitosa quedó implementada
  ( RD en `../HistRequerimientos/reserva-exitosa.md` ). El siguiente del
  flujo es el **error de reserva** ( frame 10 del `.pen` ) — su RD se
  escribe al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
