# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. Las tarjetas de canchas del Inicio quedaron
  implementadas ( RD en `../HistRequerimientos/inicio-canchas.md` ). Las
  siguientes partes de la pantalla 01 son **categorías** y el estado **sin
  canchas** ( 06 ) — sus RDs se escriben al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
