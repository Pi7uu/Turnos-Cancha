# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. La pantalla **Perfil** ( 11 ) quedó
  implementada ( RD en `../HistRequerimientos/perfil.md` ). Lo siguiente en
  el orden aprobado: **Favoritos** ( 12 ) — su RD se escribe al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
