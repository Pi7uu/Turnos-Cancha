# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. Las comodidades y la descripción del Detalle
  quedaron implementadas ( RD en `../HistRequerimientos/detalle-comodidades.md` ).
  La siguiente parte es la **parte 3 del Detalle** ( `Elegí el horario` +
  barra `Precio total / Confirmar reserva` ) — su RD se escribe al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
