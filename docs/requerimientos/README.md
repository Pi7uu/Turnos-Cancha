# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. **El prototipo está completo** ( las 12
  pantallas/estados del mockup; último RD:
  `../HistRequerimientos/inicio-filtrado.md` ). Lo siguiente en el orden
  aprobado: **fase backend** ( API `/api/`, servicios, persistencia, login
  real ) — su RD se escribe al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
