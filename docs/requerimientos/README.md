# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. La **API de autenticación + login real** quedó
  implementada ( RD en `../HistRequerimientos/api-auth.md` ) — primer pedazo
  de la fase backend. Lo siguiente en el orden aprobado: **API de canchas +
  fixtures/seed** ( y después reservas + `services.py` ) — su RD se escribe
  al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
