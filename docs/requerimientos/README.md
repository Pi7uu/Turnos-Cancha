# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. La pantalla **Favoritos** ( 12 ) quedó
  implementada ( RD en `../HistRequerimientos/favoritos.md` ) — con ella las
  4 pantallas del prototipo están completas. Lo siguiente en el orden
  aprobado: **filtrado + estado "sin canchas" ( 06 ) del Inicio** — su RD se
  escribe al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
