# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. El buscador del Inicio quedó implementado ( RD
  en `../HistRequerimientos/inicio-buscador.md` ). La siguiente parte de la
  pantalla 01 es el **selector de fecha** ( su RD se escribe al iniciar ).

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
