# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. El selector de fecha del Inicio quedó
  implementado ( RD en `../HistRequerimientos/inicio-fecha.md` ). La siguiente
  parte de la pantalla 01 son las **tarjetas de canchas** ( su RD se escribe
  al iniciar ).

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
