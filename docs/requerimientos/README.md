# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. El Detalle de cancha · hero e info quedó
  implementado ( RD en `../HistRequerimientos/detalle-hero.md` ). La
  siguiente parte es **comodidades + "Sobre esta cancha"** del Detalle
  ( parte 2 ) — su RD se escribe al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
