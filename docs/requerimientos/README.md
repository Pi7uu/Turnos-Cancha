# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. El error de reserva quedó implementado
  ( RD en `../HistRequerimientos/reserva-error.md` ) y el **flujo de reserva
  está completo**. Lo que sigue a elección: **Mis reservas** ( muestra las
  reservas creadas ), Favoritos, Perfil, el **estado "sin canchas"** ( 06 ) y
  el **filtrado** del Inicio — sus RDs se escriben al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
