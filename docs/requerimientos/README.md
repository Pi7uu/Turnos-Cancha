# docs/requerimientos/

Requerimientos activos: los que se usan para implementar, por orden de llegada.

- Sin requerimientos activos. Las categorías del Inicio quedaron implementadas
  ( RD en `../HistRequerimientos/inicio-categorias.md` ). El **layout de la
  pantalla 01 está completo**; lo que falta de esa pantalla es el estado
  **sin canchas** ( 06 ) y el **filtrado** — sus RDs se escriben al iniciar.

Cuando una feature queda implementada y verificada, su RD se mueve a
`../HistRequerimientos/`.
