# Overview del Proyecto

**TurnosCancha** es una app móvil para alquilar canchas de fútbol por turnos. Su propósito es permitir a los usuarios consultar la disponibilidad, reservar horarios y gestionar sus reservas de forma simple y rápida desde el celular. El proyecto combina un backend Django con API REST y una app Flutter (Android/iOS), cubriendo el flujo completo de catálogo de canchas, selección de turno, reserva y gestión de reservas.
